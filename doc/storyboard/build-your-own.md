# Storyboard: Build your own drink

## **User Story**
 As a customer,
 I want to customize my own drink,
 So that I can build my favorite drink within 5 minutes.
[User Story](../../features/build.feature)

## **Scenario: I want to go to "Build your Own" page**
- The user opens the app and taps on **"My Orders"** from the homepage.  
![Menu Page](../images/classic-drink/order_homescreen.png)

- Then the user will tap on **"Build your Own"** from the menu page.
![List of Drinks](../images/classic-drink/order_start-order.png)

- The user will now be on **"Build your Own"** page 
![Menu Page](../images/build-your-own/build_screen.jpg)

---

## **Scenario: I want to have multiple Toppings**
- The user sees will select their desired toppings
![Select Drink Options](../images/build-your-own/build_scenario_2.jpg)

---

## **Scenario: I want to only have 50% ice in my drink**
- The user will select the 50% option in the ice section
![Select Drink Options](../images/build-your-own/build_scenario_3.jpg)

---

## **Scenario: I have finished building my drink**
- The user clicks **place Order**, then a pop-up appears asking users if they are sure.
![Order Confirmation](../images/classic-drink/order_order-confirmation.png)

- The user sees a **Green Success** screen when pressing yes.
![Success](../images/classic-drink/order_order-success.png)

-The user will be sent back to the **Menu** page
![List of Drinks](../images/classic-drink/order_start-order.png)
